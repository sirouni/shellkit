隐私政策

更新日期：2026 年 9 月 29 日

本地工作环境

ShellKit 的终端文件、已安装软件包和设置保存在 App 的本地存储中。删除 App 会删除其本地数据。设备备份是否保留这些数据取决于你的系统备份设置。

数据收集与跟踪

ShellKit 不内置广告跟踪或开发者运营的使用分析服务，不将终端文件或命令历史自动上传给开发者。内置 shell 不需要注册 ShellKit 账号。

网络与第三方工具

下载软件包、拉取容器镜像，以及运行你安装的联网工具时，会连接相应的软件源和服务。这些服务可能接收 IP 地址及请求信息。你向 AI 工具提交的提示、代码、文件及凭据由对应服务按其隐私政策处理。请在使用前查看相关服务的政策。

凭据和文件

你在 Linux 环境中输入的账号凭据或令牌可能由相应工具保存到本地文件。请谨慎安装软件、共享文件和导出日志。ShellKit 不向开发者自动发送这些凭据。

联系支持

当你主动发送支持邮件时，我们会收到你的邮箱及邮件内容，并用于处理你的问题。GitHub Issues 是公开的，请勿提交密码、API 密钥或私人文件。如需请求删除支持邮件，请联系 sirouni@gmail.com；依法或为解决争议必须保留的信息除外。

网站

本网站由 GitHub Pages 托管，不添加分析脚本或广告 Cookie。GitHub 可能为提供托管和安全服务处理技术访问日志，适用其隐私政策。

政策更新与联系

本政策会随功能变化更新，并在本页注明日期。开发者：Xiao Wang。联系方式：sirouni@gmail.com。
