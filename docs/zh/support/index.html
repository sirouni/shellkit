你的第一个会话

1

打开 ShellKit，等待 Alpine shell 提示符出现。内置 shell 无需账号或远程 Linux 服务器。

2

用下面的命令查看环境：

uname -m
apk --version
3

创建一个文件，然后读取内容：

echo hello > hello.txt && cat hello.txt

扩展你的工具箱

Alpine 使用 apk 管理软件包。例如，安装 Python：

apk update && apk add python3

下载需要网络连接，工具与软件包兼容性可能有所不同。

为什么安装软件包会失败？

检查网络连接和 iPhone 剩余存储空间。运行 apk update 刷新软件包索引后重试。部分软件包依赖此环境尚不支持的功能；如果仍失败，请把完整命令和错误信息发给我们。

所有 Docker 镜像都能运行吗？

兼容性因镜像和工作负载而异。请选择兼容的 Linux ARM64 镜像；依赖不受支持的系统功能的镜像可能无法运行。拉取镜像需要网络和足够存储空间。联系支持时请附上镜像名称、标签和错误输出。

使用你的 AI 编程工具

ShellKit 支持用户自行安装的兼容命令行工具，包括 Claude Code。请按照工具提供方的 Linux 安装说明操作，并确认兼容性。

ShellKit 内置 Claude Code 或 AI 订阅吗？

不包含。ShellKit 提供终端环境，兼容的 AI 命令行工具由你自行安装。登录、订阅、API 使用和服务收费均由对应工具的提供方管理。

AI 工具无法安装、登录或启动，要提供哪些信息？

请提供工具名称和版本、安装方式以及完整错误信息，同时检查工具提供方的安装与账号要求。发送截图或日志前，请移除 API 密钥、令牌、密码和私有代码。

在 Safari 中打开本地服务

安装 Python 后，在你想提供访问的目录中启动一个简单服务：

python3 -m http.server 8000 --bind 0.0.0.0
  1. 打开 ShellKit 的 ports。
  2. host 填写 8080，guest 填写 8000，选择 TCP，然后点击 Publish。
  3. 在同一台 iPhone 的 Safari 中打开 http://127.0.0.1:8080。
客体服务需要监听 0.0.0.0（或所有网络接口）。仅监听客体 127.0.0.1 的服务无法通过端口映射访问。访问页面时请保持服务进程运行。

会话、后台运行与文件

能同时使用多个 shell 吗？

点击 +sh 打开新的 shell，通过标签页切换会话。关闭标签页可能中断该会话里正在运行的任务。

切换 App 后会发生什么？

在当前 iOS 状态支持的情况下，画中画可以让终端保持可见。会话运行仍受 iOS 后台和资源限制；如果任务暂停，请回到 ShellKit。请勿将它作为需要持续在线的生产服务器。

重新安装会删除文件吗？

删除 App 会移除其本地数据。删除或重新安装 ShellKit 前，请先备份重要文件。正常更新 App 时会保留可写的 Linux 工作环境。
