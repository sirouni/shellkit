Your first session

1

Open ShellKit and wait for the Alpine shell prompt. The built-in shell needs no account or remote Linux server.

2

Check your environment with these commands:

uname -m
apk --version
3

Create a small file and read it back:

echo hello > hello.txt && cat hello.txt

Add tools to your workspace

Alpine uses apk to manage packages. For example, you can install Python with:

apk update && apk add python3

Downloads require a network connection. Tool and package compatibility varies.

Why does a package install fail?

Check your network connection and available iPhone storage. Try apk update to refresh the package index, then retry the install. Some packages rely on features that are not supported in this environment. If it still fails, send us the exact command and error text.

Can I run every Docker image?

Compatibility varies by image and workload. Choose a compatible Linux ARM64 image; images that need unsupported system features may fail. Pulling images requires network access and sufficient storage. Include the image name, tag, and error output when contacting support.

Bring your AI coding tools

ShellKit supports compatible user-installed command-line tools, including Claude Code. Follow each provider’s instructions for Linux and check tool compatibility.

Does ShellKit include Claude Code or an AI subscription?

No. ShellKit provides the terminal environment. Compatible AI command-line tools are installed separately by you. Sign-in, subscriptions, API usage, and service charges are handled by each tool’s provider.

An AI tool cannot install, sign in, or start. What should I send?

Tell us the tool name and version, how you installed it, and the exact error. Check the provider’s installation and account requirements too. Remove API keys, tokens, passwords, and private code from all screenshots and logs.

Open a local service in Safari

With Python installed, start a simple server in the directory you want to serve:

python3 -m http.server 8000 --bind 0.0.0.0
  1. Open ports in ShellKit.
  2. Enter 8080 for host and 8000 for guest, select TCP, and tap Publish.
  3. Open http://127.0.0.1:8080 in Safari on the same iPhone.
The guest service must listen on 0.0.0.0 (or all interfaces). A service bound only to the guest’s 127.0.0.1 is not reachable through the mapping. Keep the server process running while using the page.

Sessions, background activity & files

Can I use more than one shell?

Tap +sh to open another shell, then use the tabs to switch sessions. Closing a shell tab may interrupt work running in that session.

What happens when I switch apps?

Picture in Picture can keep the terminal visible when supported by the current iOS state. Session activity is subject to iOS background and resource limits. If a task pauses, return to ShellKit. Do not rely on the app as an always-on production server.

Will reinstalling remove my files?

Deleting the app removes its local data. Back up important files before deleting or reinstalling ShellKit. Ordinary app updates are designed to preserve your writable Linux environment.
