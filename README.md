# ShellKit

ShellKit brings a Linux command-line workspace to iPhone.

- Website: https://sirouni.github.io/shellkit/
- Support: https://sirouni.github.io/shellkit/support/
- 中文: https://sirouni.github.io/shellkit/zh/
- Report bugs and request features: https://github.com/sirouni/shellkit/issues
- Email: sirouni@gmail.com

## Website

Bilingual static pages live in `docs/`. GitHub Pages publishes from `main` / `docs`. No build step is required. Links include the `/shellkit/` project prefix.

This repository contains the public website and issue tracker. App availability is currently marked as preparing for App Store release.

Please omit passwords, API keys, and other private information from public issues.
